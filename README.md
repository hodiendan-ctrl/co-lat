# Cờ Lật Luyện Trí Nhớ

Game lật hình luyện trí nhớ cho 2–4 người chơi: lật 2 quân giống hình thì ăn, khác hình thì úp lại.
Bàn cờ lục giác 24, 44 hoặc 80 quân; chơi được trên điện thoại, máy tính bảng và máy tính.

Chơi trực tuyến: https://hodiendan-ctrl.github.io/co-lat/

Hoặc mở file `index.html` bằng trình duyệt là chơi được, không cần cài gì.
